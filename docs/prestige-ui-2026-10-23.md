# 新米（転生）と画面整理の記録 (2026-10-23)

## 実装
- 種もみ = 通算米粒の立方根。全生産 `1 + 0.2 × 種もみ^0.4`。新米は今年の累計1兆粒かつ追加種もみ1以上。
- 持ち越し: 種もみ10/1,000/10万で金・具材・指と連携の強化、100万で「新米むすび」。
- 実行前に `…-before-rebirth` へ1件控え、書き戻して一致を確認してから初期化。失敗時は何も変えない。二重タップは2回目が0粒で無効。
- 修正: 新米前に戻す・通常インポートで `rebirthMessage` を消す（`importSave`）。回帰は `tests/runtime.test.cjs` の復元テスト。

## 画面整理（説明より配置）
- 施設行: 説明文と「◯個購入」を削除（購入数は選択中ボタン、価格・所持・毎秒は残す）。次の強化は「所持/必要数＋バー」。
- 強化行: フレーバー文を購入済み一覧へ移動。効果と価格は残す。
- 料理: 完成ボタンと重複する「完成時に◯粒使う」を削除、カードは粒数のみ。お皿は選択中に「✓」。
- 新米画面: 説明段落2つを削除（報酬は受け継ぎ一覧と確認の「もらえる/最初に戻る/残る」が担う）。
- セーブ/きせかえ/退避: 常設の補足を削除、4時間放置・きせかえ説明は「遊び方」へ。不可逆の置き換え警告、エラー、保存結果は維持。
