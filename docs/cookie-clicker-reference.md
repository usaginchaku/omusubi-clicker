# Cookie Clickerから参考にした仕組み

確認日: 2026-10-18。Wikiの一覧はv2.058表記。直接取得は403だったため、検索で取得できる各節を読み、実装に関係する数値を[本家の公開コード](https://orteil.dashnet.org/cookieclicker/main.js)と照合した。全717アイテムを個別に検証したという意味ではない。

## 一覧を系統ごとに確認

[Wikiのアップグレード一覧](https://cookieclicker.wiki.gg/wiki/Upgrades)と[全体の案内](https://cookieclicker.wiki.gg/wiki/Template:MegaNav)を起点に、次の系統を整理した。名称・文章・画像を一括移植する目的ではない。

| 系統 | 遊びに与える役割 | おむすびへの判断 |
| --- | --- | --- |
| 施設の段階強化 | 所有数の節目に買い足す理由を作る | 既存の1・10・25・50個の強化を維持 |
| カーソル・クリック | 基礎クリック強化と、生産に比例するクリックを組み合わせる | 具材と指の強化を維持 |
| フレーバークッキー | 生産全体の積み重ね | 今回は追加しない |
| Kitten・ミルク | 実績の収集を生産成長へつなぐ | 今後の検討候補。実装予定の確約ではない |
| おばあちゃん型・Synergy | 複数施設を持つ意味を作る | 今回は追加しない |
| Golden Cookie | 出現頻度・表示時間・効果時間を育て、短い大当たりを狙う | 今回の中心。金専用の強化3種類を追加 |
| 研究・Grandmapocalypse | 時間経過と購入で段階的に世界を変える | 今回は追加しない |
| 季節・サンタ・卵 | イベントや収集で別の進行目標を作る | 今回は追加しない |
| Gardenのドロップ・Fortune | 育成やニュースから強化を発見する | 今回は追加しない |
| スイッチ | 生産とイベントなどの条件を切り替える | 普段の操作を増やさないため見送り |
| Heavenly upgrades | 転生、永続強化、ドラゴン、放置、相乗効果など | [転生の一覧](https://cookieclicker.wiki.gg/wiki/Ascension)を確認。今回の保存形式・進行は維持 |
| Debug upgrades | 開発・不正操作向け | 通常の店に入れない |

## 今回の調整

本家のClick Frenzyは777倍・13秒。Frenzyは生産7倍・77秒で、別々の効果が重なる。Dragonflightの1111倍は別の育成条件に結びついている。[Wiki](https://cookieclicker.wiki.gg/wiki/Golden_Cookie)、本家コードの`gainBuff`を照合した。

おむすびでは通常のクリックを常時100倍にせず、金をつかまえた際に8%で777倍・13秒を得る。米粒の贈り物45%、生産7倍47%。この確率と生産30秒は本作向けの調整で、本家と同じ抽選ではない。金の基本待ち時間は25〜45秒。

生産7倍は指の「毎秒生産の何%」にも反映し、クリック777倍と重なる。具材の基礎クリック部分は生産7倍に含めない。同一効果は期限を更新するだけで、777×777や無限延長にはしない。クリックせずに得る米粒の贈り物は従来の上限を維持する。

実プレイ後、777倍の基礎クリック部分と生産連動部分は発動時に固定するよう変更した。途中の買い物が残りの777倍クリックを増幅し続ける問題を抑える。本作向けの調整であり、本家の仕様ではない。生産7倍の開始・終了は固定した生産連動部分にも反映し、重なりを狙う楽しさは残す。

基本の8%抽選を維持したうえで、不発が15回続いた次の金は777倍を保証する。保証込みの長期平均は約10.9%。不発回数は保存・書き出し・復元でも引き継ぐ。古いセーブは不発0回として受け入れる。

金7回で「招きむすび」（待ち時間−20%・表示時間2倍）、27回で「神様の保温ジャー」（777倍の効果時間2倍）、77回で「七福神のシフト表」（さらに待ち時間−20%・表示時間2倍）。生産7倍は保温ジャーでも30秒とし、常時に近い発動を抑えた。購入後の待ち時間の変更は次の抽選から適用する。

序盤の大当たりを禁止する案と、祭りの間は次の金を出さない案は採用しなかった。今回の目的は、大当たりや重なりを見つける喜びを作ること。[実プレイと数値検証](playtest-2026-10-18.md)では暴走と不発の偏りを確認したが、長期間の楽しさを保証するものではない。

## セーブ

[本家のセーブ](https://cookieclicker.wiki.gg/wiki/Save)と公開コードの`ExportSave`・`FileSave`・`FileLoad`を参考に、同じ文字コードをコピーでも`.txt`でも扱う。読み込み前のデータは1件退避する。旧`OMSB1|`形式を維持し、不正データの読込時は現在の進行を変更しない。

ゲーム内の「セーブ → 遊び方・このゲームについて」に本家へのリンクと「Respect for Cookie Clicker — by Orteil & Opti」を記載した。
