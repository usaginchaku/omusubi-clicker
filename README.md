# おむすびくりっかー

[遊ぶ](https://omusubi-clicker.mochibird.click/)

おむすびを握って米粒を増やし、施設と強化を買う放置クリッカーです。
おばあちゃんから始まり、だんだん世界の様子がおかしくなります。

## 遊び方

- 最初の15粒でおばあちゃんを迎えると、自動生産が始まります。
- ショップの「施設」で自動生産、「強化」でクリックや施設の生産量を増やします。購入数は1・10・100から選べます。
- ときどき現れる金のおむすびは、米粒ボーナス・30秒間の7倍生産・12秒間の77倍クリックのいずれかです。
- 図鑑で実績や施設のようすを見たり、きせかえで能力を変えたりできます。
- 施設18種類、強化88種類、通常の実績69種類、きせかえ9種類。進行に合わせて米ニュースも変わります。

## セーブと旧版の引き継ぎ

同じブラウザ・同じサイトでは5秒ごとと画面を閉じる際に自動保存します。
閉じている間の自動生産は最大4時間です。一時的な金のおむすび効果は引き継ぎません。
別端末への移動やバックアップには「セーブ」のコード書き出し・読み込みを使います。
読み込みは現在の進行を置き換えるため、必要なら先に書き出してください。

旧版の `OMSB1|` コードも読み込めます。販売・相場・具材仕入れは廃止し、
工房の在庫は旧仕様で可能だった最高売値、契約農家は購入費用の全額を米粒へ戻します。
施設、購入済みの強化・きせかえ、取得済み実績は残ります。旧工房の実績は
取得済みのものだけ図鑑に追加されます。不正なコードでは現在の進行を変更しません。
複数タブの競合や保存エラーは画面に表示します。

## 構成

- `index.html`: 固定バージョンの依存ライブラリとエントリーポイント
- `game.js`: コンテンツ、購入・生産計算、実績、保存形式と移行
- `app.jsx`: 画面、SVG、操作、タイマー、自動保存
- `styles.css`: PC・スマートフォンのレイアウト、動きの軽減設定

ビルドやパッケージインストールは不要です。GitHub Pagesで静的配信します。

## 起動確認

リポジトリ全体を静的サーバーで配信します（例: `python -m http.server 18463`）。
`app.jsx` を取得するため、HTMLファイルを直接開く `file://` ではなくHTTPでアクセスします。

React / ReactDOM は UMD 版を使うため、Babel は JSX を classic runtime へ変換する
7.28.5 に固定しています。Babel 8 の既定値では `react/jsx-runtime` の import が
生成され、通常の script として実行するこのページが空白になります。
依存ライブラリを更新するときは、実ブラウザで表示・操作を確認してください。

Node.js 18以降でテストを実行できます。起動・実コンポーネントの保存テストは
ページが指定するBabelを取得するためインターネット接続が必要です。

```sh
node --test tests/*.test.cjs
```

オフラインで経済・保存移行だけ確認する場合は `node --test tests/game.test.cjs`。
`node tools/simulate.cjs 2 3600` は毎秒2クリックで1時間の進行を計算します。
最も回収効率の良い購入を選ぶ単純な方針で、金のおむすびは含みません。
実際のプレイヤーの進め方や楽しさを保証するものではありません。
