# おむすびくりっかー

[遊ぶ](https://omusubi-clicker.mochibird.click/)

おむすびを握って米粒を増やし、施設と強化を買う放置クリッカーです。
おばあちゃんから始まり、だんだん世界の様子がおかしくなります。

## 遊び方

- 最初の15粒でおばあちゃんを迎えると、自動生産が始まります。
- ショップの「施設」で自動生産、「強化」でクリックや施設の生産量を増やします。購入数は1・10・100・1000から選べます。表示価格は、選んだ個数を買う合計額です。
- 施設画面にも購入できる強化の候補を1つ表示します。施設の1・10・25・50個で新たな強化が解放されます（購入には別途米粒が必要です）。
- 100・500・1,500・5,000回握ると指の強化が解放されます。購入すると1クリックに毎秒生産の2・3・5・10%をそれぞれ加算。全4種類で合計20%になり、施設が育つとクリックも育ちます。
- 鮭以降の具材にも毎秒生産に連動するクリック力が付きます。具材をすべて集めると合計10%を追加。基本のクリック倍率と合わせて、後半の具材にも買う意味が残ります。
- 施設を組み合わせて育てると「連携」の強化が解放され、対象の2施設の生産が25%増えます。強化画面で次の連携に必要な施設数を確認できます。
- 実績8・20・35・50個で「図鑑 → 常連」に新しいお客さんが登場します。米粒で迎えると、1人につき実績1個あたり全生産が0.25%増加。応援は加算で、旧工房の実績は数えません。「話す」は無料です。
- ときどき現れる金のおむすびは、米粒ボーナス（45%）・30秒間の7倍生産（47%）・13秒間の777倍クリック（8%）を基本に抽選します。777倍が15回続けて出なければ、次は必ず777倍。不発の回数は保存されます。
- 生産とクリックの効果は重なり、残り時間をそれぞれ表示します。777倍のクリック力は発動時を基準にし、効果中の買い物は通常時や次の777倍に反映します。生産7倍は、この基準の具材・指の生産連動分にも反映します。終了時は握った回数と稼いだ米粒を短く表示します。
- 同じ効果をもう一度得ると期限を更新し、倍率は増えません。金を7・27・77回つかまえると、出現や持続を育てる3種類の強化が解放されます。「神様の保温ジャー」は777倍だけを26秒に延長し、生産7倍は30秒です。
- 米粒ボーナスは「手持ちの15%」と「通常生産60秒分」の小さい方（切り捨て）に13粒を加えた量です。金のおむすびは15秒間表示されます。
- 図鑑で実績や施設のようすを見たり、きせかえで能力を変えたりできます。
- 図鑑の「料理」で塩むすび・オムライス・ライスバーガーを試作できます。完成時に初回だけ米粒を使い、図鑑と実績に残ります。完成品や常連の感想は無料で見返せます。オムライスのケチャップはハート・米の字・肉球に変えられます。
- 料理の「おすそわけ」では、施設を育てて9か所の届け先を解放します。料理との組み合わせごとに1枚、全27枚の絵はがきを集められます。3・12・27枚でお皿を獲得し、料理の盛り付けを変えられます。期限はなく、読み返し・付け替えは無料です。
- スマホではおむすび・米粒・下のメニューを固定し、一覧の中だけをスクロールします。タップで得た「＋○粒」は数字でも残ります。米ニュースはタップすると全文を読めます。
- 施設18種類、強化102種類（常連4人・連携7種類を含む）、通常の実績101種類、きせかえ9種類、料理3品、絵はがき27枚、お皿4種類。進行に合わせて米ニュースも変わります。

## セーブと旧版の引き継ぎ

同じブラウザ・同じサイトでは5秒ごとと画面を閉じる際に自動保存します。
閉じている間の自動生産は最大4時間です。一時的な金のおむすび効果は引き継ぎません。
別端末への移動やバックアップには「セーブ」の「最新コードをコピー」「ファイルに保存」を使います。
保存した`.txt`は「ファイルを読み込む」から復元できます。「コードで読み込む・手動コピー」では文字コードの貼り付け、表示、全選択もできます。
読み込みは現在の進行を置き換えます。直前のデータは1件退避し、同じ折りたたみ内の「読み込み前のデータを保存」で取り出せます。端末保存に失敗した場合、退避データはその画面を閉じるまでだけ保持されます。

旧版の `OMSB1|` コードも読み込めます。販売・相場・具材仕入れは廃止し、
工房の在庫は旧仕様で可能だった最高売値、契約農家は購入費用の全額を米粒へ戻します。
施設、購入済みの強化・きせかえ、取得済み実績は残ります。旧工房の実績は
取得済みのものだけ図鑑に追加されます。不正なコードでは現在の進行を変更しません。
複数タブの競合や保存エラーは画面に表示します。

## 構成

- `index.html`: 固定バージョンの依存ライブラリとエントリーポイント
- `game.js`: コンテンツ、購入・生産計算、実績、保存形式と移行
- `app.jsx`: 画面、SVG、操作、タイマー、自動保存
- `styles.css`: PC・スマートフォンのレイアウト、動きの軽減設定

ビルドやパッケージインストールは不要です。GitHub Pagesで静的配信します。

## 起動確認

リポジトリ全体を静的サーバーで配信します（例: `python -m http.server 18463`）。
`app.jsx` を取得するため、HTMLファイルを直接開く `file://` ではなくHTTPでアクセスします。

React / ReactDOM は UMD 版を使うため、Babel は JSX を classic runtime へ変換する
7.28.5 に固定しています。Babel 8 の既定値では `react/jsx-runtime` の import が
生成され、通常の script として実行するこのページが空白になります。
依存ライブラリを更新するときは、実ブラウザで表示・操作を確認してください。

Node.js 18以降でテストを実行できます。起動・実コンポーネントの保存テストは
ページが指定するBabelを取得するためインターネット接続が必要です。

```sh
node --test tests/*.test.cjs
```

オフラインで経済・保存移行だけ確認する場合は `node --test tests/game.test.cjs`。
`node tools/simulate.cjs 2 3600` は毎秒2クリックで1時間の進行を計算します。
最も回収効率の良い購入を選ぶ単純な方針で、金のおむすびは含みません。
実際のプレイヤーの進め方や楽しさを保証するものではありません。
